翻译娘MARI

Transelle 内核 · 网页翻译 + 漫画翻译

翻译引擎

三种引擎都走 OpenAI 兼容协议。Ollama 不需要 Key；DeepSeek 与自定义网关需要填 Key。 Key 只保存在本机浏览器存储里，不会上传到任何地方。 若扩展目录下放了 local-seed.json（本机私密种子，不入库）， 首次启动会自动把 Key 灌进来，也可点上面的按钮手动重新导入。

网页翻译

按站点规则圈定元素后整页翻译；动态加载的内容会自动补翻。

漫画翻译

检测页面里尺寸达标的图片，交给视觉模型识别气泡文字并翻译。 图片右下角的悬浮开关可循环切换「漫 → 幕 → 原」。

提示 漫画翻译需要真正能「看图」的模型。DeepSeek 官方文本接口不支持图片， 请把视觉引擎指向本地 Ollama 的多模态模型，或任何支持图片输入的 OpenAI 兼容网关， 并在上面的「视觉模型名」里写清模型 ID。

站点特化规则

URL 命中 pattern 时启用该规则。pattern 支持逗号分隔多个，用 * 通配。 术语表每行写 原文,译文；译文留空表示保留原文。 未添加规则时，所有站点使用默认译法。
